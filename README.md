# KESTREL — Web3 landing page (concept)

A single-page concept landing for a fictional DeFi protocol: a delta-neutral
yield vault on Base.

Built as a portfolio sample. Kestrel does not exist, no token is deployed, and
nothing here is an offer or investment advice.

## What it demonstrates

- Web3-specific blocks: tokenomics with vesting, roadmap phases, security strip,
  wallet-connect calls to action, investor FAQ
- A live-looking protocol dashboard card (TVL, APY, net delta)
- Responsive layout, no frameworks, no build step, one 17 KB HTML file
- Accessible markup: semantic sections, `details/summary` FAQ, aria labels

## Run

Open `index.html` in a browser. Nothing to install.

## Files

- `index.html` — the page
- `preview.png` — screenshot for portfolio and outreach messages
